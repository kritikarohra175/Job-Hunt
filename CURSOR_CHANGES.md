# Automation settings

Select repository `kritikarohra175/Job-Hunt` and branch `main`.

Do not use `cursor/digital-marketing-resume-automation-b93f` as the recurring automation branch.

The automation instructions are `prompts/daily_automation_prompt.md`.

Enable GitHub, Google Drive, Google Sheets, Gmail, and Cursor's browser tools.

Keep `config/runtime.md` at `RUN_MODE=REVIEW_ONLY` until a review-only run has been checked.

Google Drive stores the master resume copy and tailored PDFs. Google Sheets is the application history. The CSV in git is a backup cache.
