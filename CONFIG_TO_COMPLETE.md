# Configuration status

Approved candidate preferences and answers are recorded in the canonical files:

- `config/job_preferences.md`
- `config/answer_bank.md`
- `config/target_config_block.md`
- `config/runtime.md`

This file is not a second configuration source. Do not put conflicting values here.

`RUN_MODE` stays `REVIEW_ONLY` until that line is explicitly edited in `config/runtime.md`.
